# Déclaration des sources et des outils : mode d'emploi

Pour chaque source principale, noter titre, auteur/organisme, URL ou référence
locale, date de consultation et décision éclairée. Pour chaque usage significatif
d'IA, indiquer outil, objectif, périmètre du contenu conservé et contrôles réalisés.
Une transcription intégrale des conversations n'est pas exigée.

Exemple hors ATLAS : « Assistant utilisé pour comparer deux formes de pagination
du catalogue. J'ai retenu un paramétrage borné après vérification dans la
documentation et un test sur une page vide. J'ai corrigé l'exemple généré qui
traitait la valeur 0 comme une absence. » Décrire ensuite votre propre usage réel.

Si aucun assistant n'a été utilisé, le dire simplement et citer les sources.
Déclarer aussi les contributions des pairs, les vérifications manuelles et les
limites. L'évaluation porte sur votre maîtrise et vos preuves.
