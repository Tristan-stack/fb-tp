# Organisation du rendu à produire

ATLAS_NOM_PRENOM_M2/ contient README.md, Rapport_Audit.pdf, Architecture.pdf,
Catalogue_REST.md, Contrat_API.yaml, Exemples_JSON/, Tests_et_Validations/,
Decisions_Techniques.md, Sources_et_IA.md et Presentation.pdf.

Dans le README, donner un chemin local vers chaque partie, les versions d'outils,
les commandes réellement exécutées et les dépendances. Dans le rapport, utiliser
les dix sections prescrites par la mission. Dans Architecture.pdf, intégrer
cartographie existante, cible, séquence et matrice de responsabilités. Dans les
tests, relier chaque scénario à une opération, un besoin et une décision.

Vérifier depuis une copie indépendante du dossier que les PDF s'ouvrent, que les
liens locaux n'utilisent pas votre disque personnel et que les fichiers référencés
sont présents. Ne pas inclure de mots de passe ni de données réelles. Ne pas
ajouter un exécutable pour rendre lisible un document. Le rendu est un dossier,
sans ZIP, pour cette édition du kit.
