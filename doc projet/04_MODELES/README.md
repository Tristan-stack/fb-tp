# Gabarits de travail

Copier ces fichiers dans votre dossier de travail, puis les adapter. Les exemples
ci-dessous portent sur une bibliothèque fictive pour illustrer la méthode sans
résoudre ATLAS. Un gabarit n'est pas un rendu : remplacer le sujet et apporter
vos preuves, diagrammes et décisions. Voir la mission pour le contenu obligatoire.
